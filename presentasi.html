KONSEP TEORI DASAR

3 Struktur Kendali Pemrograman Terstruktur

Fondasi algoritma komputer dalam memecahkan masalah secara sistematis

1. Runtunan (Sequence)

Instruksi dieksekusi berurutan baris demi baris dari atas ke bawah tanpa lompatan. 

$p = 10;
$l = 5;
$luas = $p * $l;
echo $luas;

2. Percabangan (Selection)

Fokus Hari Ini: Memilih jalur eksekusi berdasarkan evaluasi kondisi Boolean (True/False). 

if ($nilai >= 75) {
    echo "Lulus";
} else {
    echo "Remedial";
}

3. Perulangan (Iteration)

Mengeksekusi instruksi berulang kali selama kondisi bernilai benar (Pertemuan berikutnya). 

for ($i=1; $i<=5; $i++) {
    echo $i;
}
SINTAKS PHP

Operator Relasional & Logika di PHP

Simbol penentu nilai kebenaran (Boolean: True atau False)

Operator Pembanding (Relasional):

== : Sama dengan nilai ($a == $b)
=== : Identik nilai & tipe data ($a === $b)
!= : Tidak sama dengan ($a != $b)
> / < : Lebih besar / Lebih kecil
>= / <= : Lebih besar sama / Lebih kecil sama
Peringatan Kritis: Jangan tertukar antara = (mengisi nilai) dan == (membandingkan nilai)!

Operator Logika Majemuk:

&& (AND): Wajib KEDUA kondisi bernilai True.

if ($nilai >= 75 && $absen >= 80)

|| (OR): Cukup SALAH SATU kondisi True.

if ($isMember == true || $total >= 500000)
STRUKTUR 1

Percabangan Tunggal (if) & Ganda (if...else)

Pilihan aksi dasar dalam PHP untuk menangani satu atau dua alternatif kondisi

Percabangan Tunggal (if)

Hanya mengeksekusi aksi jika kondisi bernilai TRUE. Jika FALSE, dilewati begitu saja. 

$totalBelanja = 120000;

if ($totalBelanja >= 100000) {
    echo "Dapat Kupon Undian!";
}

Percabangan Ganda (if...else)

Menyediakan dua alternatif: Blok if jika True, blok else jika False. 

$nilai = 68;

if ($nilai >= 75) {
    echo "Kompeten / Lulus";
} else {
    echo "Belum Kompeten (Remedial)";
}
STRUKTUR 2

Percabangan Bertingkat (if...elseif...else)

Mengevaluasi serangkaian kondisi berjenjang dari atas ke bawah

Alur Evaluasi Berjenjang:

  1. PHP mengecek kondisi 1 paling atas.
  2. Jika False, berlanjut mengecek elseif berikutnya.
  3. Begitu ada yang True, blok dieksekusi dan percabangan langsung selesai.
  4. Jika semua False, blok else terakhir yang dijalankan.
Tips Logika: Urutkan kondisi dari angka batas terbesar ke terkecil agar tidak terjadi benturan logika!

Contoh Konversi Nilai Siswa:

$skor = 84;

if ($skor >= 90) {
    $grade = "A (Sangat Baik)";
} elseif ($skor >= 80) {
    $grade = "B (Baik)";
} elseif ($skor >= 70) {
    $grade = "C (Cukup)";
} else {
    $grade = "D (Kurang)";
}
echo "Grade: " . $grade;
STRUKTUR 3

Percabangan Bersarang (Nested If)

Struktur percabangan di dalam percabangan untuk keputusan bertingkat

Kapan Nested If Digunakan?

Ketika sebuah keputusan lanjutan HANYA diuji setelah keputusan sebelumnya dinyatakan lolos verifikasi.

Contoh Riil Industri:
1. Cek kecocokan Username & Password.
2. JIKA cocok, periksa Role Pengguna (Admin vs Kasir).
3. JIKA salah sejak awal, tolak akses dan jangan periksa role!

Contoh Kode PHP Nested If:

$loginSukses = true;
$role = "Admin";

if ($loginSukses) {
    // Percabangan di dalam percabangan
    if ($role == "Admin") {
        echo "Buka Panel Admin";
    } else {
        echo "Buka Halaman Kasir";
    }
} else {
    echo "Kombinasi Akun Salah!";
}

PANDUAN & DEBUGGING

Tips Menjalankan & Mengatasi Error PHP

Jangan takut error! Error adalah petunjuk dari komputer agar kode kita sempurna

Langkah Menjalankan Kode:

  1. Pastikan modul Apache di XAMPP berstatus RUNNING (Hijau).
  2. Simpan file di dalam folder: C:/xampp/htdocs/percabangan/.
  3. Buka browser dan buka: http://localhost/percabangan/nama_file.php.
  4. Tekan tombol F5 (Refresh) setiap kali memperbarui kode di VS Code.

3 Error Paling Sering Muncul:

1. Parse Error: unexpected token ";"
-> Lupa menulis tanda titik koma (;) pada baris sebelumnya.

2. Kurung Kurawal { } Tidak Berpasangan
-> Pastikan setiap kurung buka { memiliki kurung tutup }.

3. Tertukar Simbol = dengan ==
-> Dalam if(...) wajib gunakan ==!

KESIMPULAN

Rangkuman Materi Hari Ini
